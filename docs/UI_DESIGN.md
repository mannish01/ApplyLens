# ApplyLens — UI/UX Design Specification

## 1. Design Direction

Dark Premium SaaS.

The interface should feel modern, clean,
professional and easy to navigate.

## 2. Color Palette

- Background: #0B1020
- Surface: #111A2E
- Elevated: #17223A
- Primary: #8B7CFF
- Success: #20C997
- Warning: #F5B942
- Danger: #F87171
- Text: #F8FAFC
- Muted: #94A3B8
- Border: #26334D

## 3. Typography

- Inter or Geist for interface text.
- JetBrains Mono for technical information.

## 4. Layout

- Sidebar: approximately 250px.
- Header: approximately 68px.
- Maximum content width: 1440px.
- Responsive navigation.
- Consistent 4px-based spacing scale.

## 7. Responsive Behavior

### Desktop
Full sidebar and multi-column layouts.

### Tablet
Compact navigation and flexible grids.

### Mobile
Collapsible navigation drawer and stacked layouts.

## 8. UX Principles

- Clear navigation.
- Consistent visual hierarchy.
- Accessible contrast.
- Helpful error messages.
- Loading and empty states.
- Clear feedback after user actions.
- Responsive layouts.
