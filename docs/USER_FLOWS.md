# ApplyLens — User Flows

## 1. Registration and Onboarding

1. User opens ApplyLens.
2. User registers an account.
3. User authenticates successfully.
4. User completes their student profile.
5. User reaches the dashboard.

## 2. Opportunity Discovery

1. User opens Explore Opportunities.
2. User searches or applies filters.
3. User opens an opportunity.
4. User views its requirements and details.
5. User checks eligibility.
6. User saves the opportunity if interested.

## 3. Application Tracking

1. User opens saved opportunities.
2. User selects an opportunity.
3. User creates an application record.
4. User updates application status.
5. User monitors progress in the tracker.

## 4. Document Intelligence

1. User uploads an opportunity PDF.
2. System validates the file.
3. System securely stores the document.
4. System extracts text with page references.
5. AI extracts structured requirements.
6. User reviews extracted information.
7. System evaluates eligibility.
8. User asks questions about the document.
9. AI responds using retrieved document content
   and supporting page references.

## 5. Eligibility Evaluation

1. User selects an opportunity.
2. System retrieves the student's profile.
3. System retrieves mandatory requirements.
4. System compares profile data with requirements.
5. System produces one of three results:
   - ELIGIBLE
   - NOT_ELIGIBLE
   - NEEDS_REVIEW
6. System displays reasons and supporting evidence.
